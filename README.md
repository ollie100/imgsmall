# 智能图片优化工具

一款基于浏览器的智能图片优化工具，能够自动压缩图片并保持原始清晰度，特别优化了大图片处理，可将图片控制在500KB以内。所有处理都在本地浏览器中完成，不会上传到服务器，保护您的隐私和数据安全。

## 功能特点

- 🎯 **智能压缩**：自动选择最佳压缩参数，保持图片清晰度
- 📏 **尺寸控制**：确保压缩后图片大小控制在500KB以内
- 📁 **批量处理**：支持同时上传和处理多张图片
- ⚡ **一键处理**：简化操作流程，无需手动调整参数
- 👀 **实时预览**：压缩前后效果对比
- 📱 **响应式设计**：完美适配桌面和移动设备
- 🔒 **隐私保护**：所有处理均在本地完成
- 🚀 **高速处理**：采用高质量压缩算法，处理迅速
- 💡 **渐进式优化**：智能调整压缩参数，避免压缩后文件反而变大

## 使用方法

### 本地运行

1. 下载所有文件到本地文件夹
2. 直接双击 `index.html` 在浏览器中打开
3. 或者使用本地服务器：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 使用Node.js
   npx serve .
   ```

### 使用步骤

1. **上传图片**：
   - 拖拽图片到上传区域
   - 或点击"选择图片"按钮
   - 支持多选进行批量处理

2. **自动优化**：
   - 系统自动选择最佳压缩参数
   - 智能保持原始清晰度
   - 仅对大尺寸图片进行适当缩放

3. **预览和下载**：
   - 实时显示优化前后对比
   - 查看文件大小优化效果
   - 点击"下载优化图片"保存

4. **批量处理**：
   - 选择多个文件自动进入批量模式
   - 每个文件单独显示处理状态
   - 支持一键下载所有优化图片

## 技术实现

- **前端**：纯HTML/CSS/JavaScript
- **压缩**：使用HTML5 Canvas API进行图片处理和压缩，采用渐进式压缩算法，通过多次尝试不同的压缩参数，确保图片质量和大小的最佳平衡
- **兼容性**：支持现代浏览器（Chrome、Firefox、Safari、Edge）
- **智能判断**：对于压缩后反而变大的情况，会返回原始图片；对于大PNG文件，会智能转换为更高效的格式

## 注意事项

- 所有处理都在浏览器本地完成，不会上传任何数据
- 大文件处理可能需要一些时间，请耐心等待
- 建议在桌面浏览器使用以获得最佳体验
- **优化效果**：智能控制图片大小在500KB以内，保持原始图片清晰度，人眼几乎无法察觉差异
