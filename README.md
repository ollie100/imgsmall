# 智能图片优化工具

一个基于浏览器的智能图片优化工具，自动压缩并保持原始清晰度，支持JPG、PNG、WebP格式。

## 功能特点

- 🖼️ 支持多种图片格式：JPG、PNG、WebP
- 📁 支持单文件和批量处理
- 🎯 智能压缩：自动保持原始清晰度
- 🔒 完全本地处理，保护隐私安全
- 📱 响应式设计，支持移动设备
- ⚡ 一键处理，无需复杂设置
- 🎨 高质量算法，视觉无损压缩

## 使用方法

### 本地运行

1. 下载所有文件到本地文件夹
2. 直接双击 `index.html` 在浏览器中打开
3. 或者使用本地服务器：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 使用Node.js
   npx serve .
   ```

### 使用步骤

1. **上传图片**：
   - 拖拽图片到上传区域
   - 或点击"选择图片"按钮
   - 支持多选进行批量处理

2. **自动优化**：
   - 系统自动选择最佳压缩参数
   - 智能保持原始清晰度
   - 仅对大尺寸图片进行适当缩放

3. **预览和下载**：
   - 实时显示优化前后对比
   - 查看文件大小优化效果
   - 点击"下载优化图片"保存

4. **批量处理**：
   - 选择多个文件自动进入批量模式
   - 每个文件单独显示处理状态
   - 支持一键下载所有优化图片

## 技术实现

- **前端**：纯HTML/CSS/JavaScript
- **压缩**：使用Canvas API进行图片处理
- **兼容性**：支持现代浏览器（Chrome、Firefox、Safari、Edge）

## 注意事项

- 所有处理都在浏览器本地完成，不会上传任何数据
- 大文件处理可能需要一些时间，请耐心等待
- 建议在桌面浏览器使用以获得最佳体验

## 浏览器支持

- Chrome 50+
- Firefox 45+
- Safari 10+
- Edge 12+
